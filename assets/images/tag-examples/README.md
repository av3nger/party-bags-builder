# Name Tag Color Examples

This directory should contain example photos of the 3D printed name tags in different color combinations.

## Required Images

The following images are required (400×300 JPG recommended):

1. **red-white-tag.jpg** - Red tag on white base
2. **blue-yellow-tag.jpg** - Blue tag on yellow base
3. **pink-white-tag.jpg** - Pink tag on white base
4. **green-black-tag.jpg** - Green tag on black base
5. **purple-silver-tag.jpg** - Purple tag on silver base
6. **orange-blue-tag.jpg** - Orange tag on blue base

## Guidelines

- **Format**: JPG or JPEG
- **Dimensions**: 400×300 pixels (width × height)
- **File size**: Keep under 200KB for optimal performance
- **Content**: Clear photo showing the tag color combination
- **Background**: Clean, neutral background preferred
